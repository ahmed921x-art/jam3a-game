# حملة إطلاق «بايو»

كل الصور مأخوذة من اللعبة الحقيقية (لقطات حيّة بدقة 3x)، والموسيقى مولَّدة برمجياً (بلا حقوق نشر).

| الملف | المقاس | الاستخدام |
|---|---|---|
| `video/bio-ad.mp4` | 1080×1920، 21.8 ث، مع موسيقى | ريلز إنستقرام، تيك توك، سناب، ستوري، شورتس |
| `video/scenes/s1.png` | 1080×1920 | غلاف الفيديو (Cover) |
| `posts/post1.png` | 1080×1350 | بوست الإطلاق |
| `posts/post2.png` | 1080×1350 | طريقة اللعب |
| `posts/post3.png` | 1080×1350 | تحدّي سؤال (تفاعل بالتعليقات) |

**ترتيب النشر المقترح:** الفيديو يوم الإطلاق ← بوست 1 بنفس اليوم ← بوست 2 بعد يومين ← بوست 3 بعدها بيومين، ثم ستوري فيها الإجابة.

## إعادة التوليد
من جذر المشروع، شغّل خادماً محلياً `python -m http.server 8777`، ثم:
```bash
bash marketing/tools/capture.sh        # لقطات اللعبة → marketing/shots/
bash marketing/tools/render.sh         # البوستات والمشاهد ← design.html
python marketing/tools/build_video.py  # الفيديو + الموسيقى (يتطلب ffmpeg و numpy)
```
النصوص والتصميم في `tools/design.html`، ومدد المشاهد والانتقالات في `tools/build_video.py`.
