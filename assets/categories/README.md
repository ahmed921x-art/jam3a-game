# صور الفئات

## الخطوات
1. ضع الصورة في هذا المجلد (`assets/categories/`).
2. افتح `questions-bio.js` وابحث عن `CATEGORY_IMAGES`.
3. أضف سطراً فيه **معرّف الفئة** واسم الملف، مثل:
   ```js
   const CATEGORY_IMAGES = {
     cell: "cell.webp",
     kuwait: "kuwait.webp",
   };
   ```
4. احفظ وحدّث الصفحة.

الفئة اللي ما لها صورة تظهر برمزها التعبيري كالعادة.

## مواصفات الصورة
- **مربعة**، يكفي 256×256 بكسل. تُعرض داخل خلية سداسية، فخلّ الشيء المهم في المنتصف لأن الأطراف تنقص.
- الصيغة **WebP** أو PNG، وحجم أقل من 50 كيلوبايت إن أمكن.
- يُفضّل رسم بخط أسود على خلفية فاتحة أو شفافة، مثل رسومات الشعار، حتى تتناسق مع بعض.
- اسم الملف بالإنجليزي وبدون مسافات، مثل `cell.webp`.
- استخدم صوراً تملكها أو مسموحاً باستخدامها، لأن اللعبة منشورة للعامة.
