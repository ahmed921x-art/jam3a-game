# صور الأسئلة والإجابات

## من صفحة الأدمن (`admin.html`) — الأسهل
في محرر الفئة اضغط زر 🖼 بجانب السؤال ثم **📤 رفع** واختر الصورة من جهازك؛ تُصغَّر تلقائياً (900px) وتُحفظ مع الفئة.
لصورة الفئة نفسها اضغط المربع السداسي بجانب حقل الصورة (تُقص مربعة 256px).

أو بدل الرفع: ضع الصورة في هذا المجلد (`assets/questions/`) أو استخدم رابط `https://`، واكتب:
   - **صورة السؤال**: تظهر مع السؤال (مثل: «ما اسم هذه العضيّة؟»)
   - **صورة الإجابة**: تظهر بعد عرض الإجابة
3. احفظ ونشر.

## في ملفات الأسئلة (للفئات الأساسية)
```js
{ points: 400, q: "ما اسم هذه العضيّة؟", a: "الميتوكوندريا", img: "assets/questions/mito.webp", aImg: "assets/questions/mito-labeled.webp" }
```

## مواصفات
- WebP أو PNG أو JPG، وعرض حوالي 1000 بكسل يكفي، وحجم أقل من 200 كيلوبايت.
- صورة السؤال تُعرض بارتفاع أقصاه ثلث الشاشة تقريباً، وصورة الإجابة أصغر منها.
- لا تكتب الإجابة داخل صورة السؤال.
- الروابط المقبولة تبدأ بـ `assets/` أو `https://` فقط.
