# وسائط أسئلة المباراة

كل محتوى الوسائط في `gaming-pack.js`، ويُعرض مباشرة من مصادره (لا شيء مُنزَّل في المستودع):

| الفئة | المصدر |
|---|---|
| موسيقى وأصوات الألعاب، شارات الأنمي، شارات كرتون زمان | YouTube مضمَّن — مقطع قصير من مكان عشوائي آمن، والفيديو مخفي حتى الكشف |
| خمّن اللعبة من الفيديو | مقاطع لعب من YouTube (الحواف مقصوصة حتى لا يظهر العنوان) |
| خمّن اللعبة من اللقطة | لقطات متجر Steam بدقة 1920×1080 |
| شخصيات الألعاب | رندرات الموقع الرسمي لـ Super Smash Bros، وويكيبيديا لغير الموجودين فيه |
| شخصيات الأنمي والكرتون، خمّن الأنمي من الصورة | AniList |
| خمّن الجهاز | صور Wikimedia Commons الحرّة (1280px) |

يحتاج اللعب اتصالاً بالإنترنت.

## كيف لا يُسمع اسم الكرتون في الأغنية؟

لكل شارة فترات آمنة `win` محسوبة من **كلمات الأغنية بتوقيتها** (موقع lrclib، أو النص
التلقائي في YouTube): كل سطر يُذكر فيه اسم الكرتون مستبعد. اللعبة تختار كل مرة مقطعاً
عشوائياً داخل هذه الفترات، طوله حسب الصعوبة: 12 ثانية (200)، 8 (400)، 5 (600).

## إضافة محتوى

الأسهل: اطلب من Claude داخل المشروع، مثلاً «ضيف 10 شارات أنمي جديدة» — يتبع
`.claude/skills/add-quiz-content/SKILL.md` ويستخدم الأدوات التالية:

```bash
node tools/content/yt-search.js "شارة الكابتن رابح" 5                    # مقاطع YouTube + هل تسمح بالتضمين
node tools/content/safe-windows.js --song "ريمي" --ban "ريمي"             # فترات آمنة من كلمات الأغنية
node tools/content/steam-shots.js "Elden Ring"                           # لقطات Steam
node tools/content/find-image.js smash mario luigi                       # شخصيات الألعاب
node tools/content/anime-image.js character "Levi"                       # شخصيات الأنمي والكرتون
node tools/content/anime-image.js anime "Haikyuu"                        # صور الأنمي العريضة
node tools/content/find-image.js commons "Wii-console.jpg"               # صور الأجهزة
node tools/content/check-pack.js                                         # فحص كل شيء قبل النشر
```

## أثناء اللعب (للمقدّم — اختياري)
- **➕ 5 ثوانٍ**: يكمّل المقطع 5 ثوانٍ إضافية.
- **📌 ابدأ من هنا**: يثبّت بداية مقطع على هذا الجهاز (لا حاجة له عادةً — البدايات محسوبة مسبقاً).
