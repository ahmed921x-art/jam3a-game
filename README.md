# 🧬 بايو (BIO) — مسابقة علمية بين فريقين

لعبة مسابقات جماعية لفريقين ومقدّم واحد على شاشة واحدة، فيها أسئلة في الأحياء والعلوم والمعلومات العامة وعن الكويت. موقع ثابت (HTML/CSS/JS) بلا أدوات بناء، ويمكن تثبيته كتطبيق (PWA).

**العب الآن:** https://ahmed921x-art.github.io/jam3a-game/

![بايو](assets/og-image.png)

## المميزات
- **مباراة «سين وجيم»** (الوضع الافتراضي): فريق ضد فريق (بأسماء ولاعبين يتناوبون) أو واحد ضد واحد، لوحة فئات × نقاط (100–500 أو 200–1000)، كل خانة تُلعب مرة واحدة، **سرقة** بعد الإجابة الخاطئة (كاملة/نصف/إيقاف)، خصم اختياري، مؤقت إجابة، تراجع عن آخر سؤال، وحفظ تلقائي للاستكمال.
- **أسئلة تفاعلية** على نفس اللوحة: صورة مشوّشة تتضح، أغانٍ وموسيقى من YouTube مخفية حتى الكشف (تشغيل/إيقاف/إعادة/تقديم/صوت)، ومقاطع لعب من YouTube مقصوصة الحواف حتى لا يظهر العنوان، وصور للشخصيات مع الإجابة. انظر `assets/media/README.md`.
- **لوحة عادلة**: في كل فئة سؤالان لكل قيمة (200 200 · 400 400 · 600 600) — خانة لكل فريق، والقيم تزيد مع الصعوبة. عدد الفئات 3 أو 4 أو 5 أو 6، والقيم قابلة للتغيير.
- **🎮 ألعاب فيديو** (`gaming-pack.js`): موسيقى الألعاب (22)، أصوات الألعاب (17)، خمّن اللعبة من الفيديو (12)، خمّن اللعبة من اللقطة (22 لقطة Steam)، شخصيات الألعاب (26)، خمّن الجهاز (18)، خمّن بالإيموجي (18)، معلومات وألغاز الألعاب (23).
- **🎌 أنمي**: شارات الأنمي (24)، شخصيات الأنمي (28)، خمّن الأنمي من الصورة (23)، معلومات الأنمي (20).
- **📺 كرتون زمان**: شارات سبيستون (21)، شخصيات كرتون زمان (19)، معلومات كرتون زمان (17).
- **مقاطع الأغاني ذكية**: مقطع قصير من مكان عشوائي آمن كل مرة (12 ثانية للسهل، 8 للمتوسط، 5 للصعب)، والأماكن محسوبة من كلمات الأغاني حتى لا يُسمع اسم الكرتون أو الأنمي أبداً.
- **إضافة محتوى بسهولة**: اطلب من Claude «ضيف أسئلة…» فيتبع مهارة `.claude/skills/add-quiz-content`، أو استخدم أدوات `tools/content/`. انظر `assets/media/README.md`.
- **72 فئة و1038 سؤالاً ثابتاً**: منها تحدي الأغاني بالفيديو، وخمس فئات إضافية للدماغ والبحار ورحلات الفضاء وتصحيح المعلومات وتاريخ كأس العالم. لا تتكرر أسئلة الفئة في مباراتين متتاليتين قبل نفاد بنك مستواها. قد تظهر فئات إضافية من الكتالوج السحابي عند الاتصال.
- **بحث وتصفية للفئات**: أحياء وعلوم / الكويت / عامة / فئاتي / المختارة.
- **وسائل مساعدة** لكل فريق: 🔄 تبديل السؤال · 📞 اتصال بصديق (دقيقة يتوقف فيها المؤقت) · ✌️ جوابان.
- **👑 الجولة الذهبية** (اختيارية) برهان سريع، و**⚡ شوط فاصل** عند التعادل.
- **تصحيح النقاط يدوياً** للمقدّم من لوحة اللعب.
- **محرر فئات** خاص بكل مستخدم + تصدير واستيراد JSON.
- **حسابات Google** (Firebase) أو اللعب كضيف، مع إحصائيات وإنجازات وسجل مباريات.
- **العربية RTL والإنجليزية LTR**، والوضع الداكن والفاتح، وخمسة ألوان مأخوذة من خلايا الشعار.
- **مصمّمة للجوال أولاً**: أهداف لمس 44–56px، ودعم لوحة المفاتيح والتركيز، وتحترم «تقليل الحركة».

## التشغيل
```bash
python -m http.server 8765
# ثم افتح http://localhost:8765
```
الخادم مطلوب للـ Service Worker، وكل الباقي يعمل بفتح `index.html` مباشرة.

## اختصارات أثناء السؤال
| المفتاح | الوظيفة |
|---|---|
| `Space` | عرض الإجابة |
| `1` / `2` | النقاط للفريق الأول / الثاني (بعد عرض الإجابة) |
| `0` | ولا أحد |
| `Esc` | إغلاق النافذة أو الرجوع للوحة |

## إضافة أسئلة
من داخل اللعبة: **فئاتي الخاصة**. أو في ملف أسئلة:
```js
CATEGORIES.push({
  id: "my-cat",
  name: "فئتي",
  icon: "🧫",
  group: "bio", // bio | kuwait | general (اختياري)
  questions: [
    { points: 200, q: "السؤال؟", a: "الجواب" },
    // سؤالان على الأقل لكل قيمة: 200 / 400 / 600
  ],
});
```
مراجعة المحتوى ومصادره: `CONTENT-REVIEW.md`.
