# 🎯 لَمة — لعبة المسابقات

لعبة مسابقات عربية احترافية بين فريقين على غرار seenjeem — فئات، أسئلة، نقاط، ومؤثرات على مستوى عالمي. موقع ثابت بالكامل (HTML/CSS/JS) بدون أي مكتبات خارجية، ويعمل بدون اتصال (PWA).

## ✨ المميزات

- **صفحة هبوط سينمائية** — خلفية نجوم + أورورا متحركة، شريط فئات، إحصائيات حيّة، شرح اللعب.
- **نظام حسابات** — تسجيل/دخول/ضيف، أفاتار، ملف شخصي بإحصائيات. (محلي، جاهز للترقية لـ Firebase)
- **سجل مباريات + إنجازات** مربوطة بالحساب.
- **46 فئة / 434 سؤال** مع اختيار عشوائي يتجدد كل لعبة.
- **محرر فئات وأسئلة** خاص بكل مستخدم + تصدير/استيراد JSON.
- **وسائل مساعدة**: ✖️ نقطتك ونص (×1.5) · 🥷 جاوب واسرق · 📞 وقت إضافي.
- **👑 الجولة الذهبية** (اختيارية): كل فريق يراهن بجزء من نقاطه على سؤال أخير — صح تضيف الرهان، خطأ تخصمه.
- **شوط فاصل حاسم** عند التعادل + عرض الإجابة تلقائياً عند انتهاء الوقت.
- **إحصائيات المباراة**: عدد الإجابات الصحيحة لكل فريق في شاشة النتيجة.
- **5 ثيمات ألوان** + **واجهة ثنائية اللغة** (عربي/إنجليزي).
- **أصوات** (Web Audio) + **موسيقى خلفية** + **كونفيتي وألعاب نارية**.
- **حفظ واستكمال** اللعبة · مؤقت قابل للضبط · اختصارات لوحة مفاتيح.
- **PWA** — تثبيت كتطبيق وعمل بدون إنترنت.

## 🚀 التشغيل

افتح `index.html` مباشرة، أو شغّل سيرفراً محلياً (مطلوب لميزة PWA):

```bash
python -m http.server 8765
# ثم افتح: http://localhost:8765
```

## ⌨️ اختصارات أثناء السؤال

| المفتاح | الوظيفة |
|--------|---------|
| `مسافة` | عرض الإجابة |
| `1` / `2` | منح النقاط للفريق الأول / الثاني |
| `0` | لا أحد أجاب |
| `Esc` | إغلاق النافذة |

## 📁 الملفات

| الملف | الوظيفة |
|------|---------|
| `index.html` | الهيكل وكل الشاشات والنوافذ |
| `style.css` · `landing.css` | التصميم والثيمات |
| `game.js` | منطق اللعبة الكامل |
| `questions.js` · `questions-extra.js` · `questions-kuwait.js` · `questions-pack2.js` | قاعدة الأسئلة (46 فئة) |
| `i18n.js` | نظام اللغتين |
| `auth.js` | نظام الحسابات المحلي |
| `sounds.js` | محرك الأصوات والموسيقى |
| `effects.js` | الكونفيتي وخلفية النجوم |
| `manifest.json` · `sw.js` · `icon.svg` | ملفات PWA |

## 🛠️ تخصيص الأسئلة

أضف فئاتك من داخل اللعبة (زر **محرر الفئات**)، أو عدّل `questions-extra.js` مباشرة:

```js
CATEGORIES.push({
  id: "my-cat",
  name: "فئتي",
  icon: "🎲",
  questions: [
    { points: 200, q: "السؤال؟", a: "الجواب" },
    // سؤالان على الأقل لكل قيمة: 200 / 400 / 600
  ],
});
```

## 🔮 الترقية المستقبلية

نظام الحسابات الحالي محلي (localStorage). للحسابات عبر الأجهزة، استبدل `auth.js` بـ **Firebase Authentication** (Google Sign-in + Firestore) مع الحفاظ على نفس الواجهة (`Auth.current()`, `Auth.key()`, `Auth.onChange()`).
