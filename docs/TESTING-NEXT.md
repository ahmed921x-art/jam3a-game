## الحدود المعروفة

- مقاطع YouTube تحتاج اتصالًا بالشبكة، وقد تمنعها إعدادات التضمين أو المتصفح. نجاح oEmbed لا يكفي لضمان التشغيل المضمن؛ رابط المشاهدة الخارجي يحافظ على كون السؤال فيديو فقط. لم يُختبر تشغيل المقاطع على Safari أو أجهزة حقيقية.
- اختبرنا تشغيل PWA دون اتصال عبر خادم محلي متوقف ومسار GitHub Pages؛ لم نختبر تنصيب التطبيق على جهاز حقيقي أو تسجيل الدخول الفعلي بحساب Google.
- واجهة التحكم مترجمة للإنجليزية، لكن نصوص بنك الأسئلة وإجاباتها عربية كما في المحتوى الأصلي.
